# Modpack guide

## Requirements

- Minecraft `1.20.1`
- Forge `47.4.20` or compatible `47.x`
- Create `6.0.8-289` or compatible `6.0.x`
- Java `17`

## Runtime dependencies

- `Create` is the only gameplay mod required by this addon.
- The release JAR does not bundle extra mods.
- Install this addon on both client and server.

## What the addon does

- Connects Create fluid pipes automatically.
- Shows a ghost preview before placement.
- Provides route priorities, anchors, preview lock, and air confirmation.
- Supports automatic/manual mechanical pumps.
- Supports copper casing and glass/default pipe style modes.
- Checks survival inventory before placement.

## Recommended versions

- Minecraft `1.20.1`
- Forge `47.4.20` or newer `47.x`
- Create `6.0.8-289`
- Create: Pipe Connector `1.0.0`
